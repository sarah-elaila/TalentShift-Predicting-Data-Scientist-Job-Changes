# TalentShift-Predicting-Data-Scientist-Job-Changes
Predicts whether data science trainees will seek a job change, using the HR Analytics dataset. Includes EDA, data cleaning, encoding and scaling, and compares Decision Tree, Random Forest, Logistic Regression, SVM, and XGBoost with ROC-AUC evaluation. The best model (XGBoost) is saved with joblib for deployment.
